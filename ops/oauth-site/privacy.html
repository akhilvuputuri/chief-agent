Chief privacy notice

Updated 21 September 2026. Chief is a privately operated personal assistant for its configured owner.

Google information

With account authorization, the assistant can search and read Gmail messages, read calendar events and create owner-approved calendar events, and read or update the Google Sheets used by the application. It does not send, delete or modify email. Calendar creation requires confirmation in Telegram.

Processing and storage

Relevant email, calendar and spreadsheet information can be included in model requests through the configured AI API providers to answer the owner's requests. Replies are delivered through Telegram; voice replies, when enabled, use the configured speech provider. Conversations, tool results, saved records and diagnostic traces may contain this information and are stored in the application's private database on its cloud host. OAuth credentials are stored separately in the server's private configuration and are not published on this website.

Information is retained until removed through an available application function or by the operator. Revoking Google access prevents future authorized requests but does not automatically delete information already saved. The owner can request deletion through the operator; deleting records may require removing dependent history and traces.

Use and control

The application uses Google data to provide the owner's requested assistant functions. It does not sell Google user data or use it for advertising. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The owner can revoke authorization at Google Account connections. For questions or deletion requests, use the developer contact shown on the Google consent screen. This website contains no tracking scripts or advertising.
